# Changes Made - January 22, 2026

## Summary
Consolidated CORE code from individual platform targets into `shared/` directory for true platform parity. The HA addon and Windows standalone now share identical core code.

## What Changed

### 1. CORE Files Moved to shared/ Root
These files are now the SOURCE OF TRUTH and sync to both platforms:

| File | Purpose |
|------|---------|
| `shared/obs.py` | Logging/observability |
| `shared/recording.py` | Audio recording/mixing engine |
| `shared/theme.py` | Theme management |
| `shared/track.py` | Track/layer handling |
| `shared/network_speakers.py` | Network speaker discovery |
| `shared/streaming.py` | Streaming to network speakers |
| `shared/utils.py` | Shared utilities |

**Import pattern**: `from sonorium.obs import logger`

### 2. Core Business Logic in shared/core/
Channel system, state management, and managers:

| File | Purpose |
|------|---------|
| `shared/core/channel.py` | Channel system |
| `shared/core/state.py` | State management (platform-agnostic paths) |
| `shared/core/speaker_manager.py` | Speaker management |
| `shared/core/cycle_manager.py` | Theme cycling |
| `shared/core/theme_metadata.py` | Theme metadata |
| `shared/core/log_collector.py` | Log collection |

**Import pattern**: `from sonorium.core.channel import ChannelManager`

### 3. Web UI Moved to shared/web/
The web frontend is now IDENTICAL across platforms:

| File | Purpose |
|------|---------|
| `shared/web/static/js/app.js` | Main frontend (189KB, all features) |
| `shared/web/static/js/api.js` | API client |
| `shared/web/static/css/styles.css` | Styles |
| `shared/web/templates/index.html` | Main HTML template |
| `shared/web/app.py` | FastAPI app factory |
| `shared/web/api_v2.py` | Full API implementation |

### 4. Sync Script Updates
`scripts/sync_shared.py` now handles:
- `ROOT_FILES` - Files that sync to package root (sonorium.xxx imports)
- `SHARED_MAPPINGS` - Directories that sync to subfolders
- **Merge mode** for `core/` and `web/` - preserves platform-specific files

### 5. Standalone Web Folder Relocated
- **Old location**: `app/core/web/` (outside sonorium package)
- **New location**: `app/core/sonorium/web/` (inside package, synced)
- Updated `web_api.py` path reference

## What Stays Platform-Specific

### HA Addon Only (`sonorium_addon/sonorium/`)
- `ha/` folder - HA registry, MQTT entities, media controller
- `core/session_manager.py` - Uses HA registry for sessions
- `core/group_manager.py` - Uses HA registry for groups
- `core/hybrid_discovery.py` - Combines HA + direct discovery
- `settings.py` - HA options/config loading
- `entrypoint.py` - HA startup

### Standalone Only (`app/core/sonorium/`)
- `config.py` - Standalone config management
- `local_stream_player.py` - Local audio playback
- `audio_output.py` - Audio device management
- `update.py` - Auto-update system
- `main.py` - Standalone entry point
- `web_api.py` - Standalone API (needs alignment with HA API)

# /project:status - Quick Status Check

A quick look at where things stand without starting a full session.

## What You'll See

```
## 📊 Sonorium Status

### Git
- Branch: [current branch]
- Uncommitted changes: [yes/no]
- Last commit: [brief description]

### Current Work (from Summary.md)
[What's actively being worked on]

### Top Tasks (from TODO.md)  
1. [Highest priority task]
2. [Next task]
3. [Next task]

### Quick Commands
- /project:start → Full session startup
- /project:review → Check code before saving
```

## When to Use This

- Resuming after a break
- Quick check before starting work
- See if there's uncommitted work

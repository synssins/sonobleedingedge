# /project:feature - Implement Something New

Use this when you want to add a new feature or capability.

## How It Works

### Step 1: Understanding
I'll make sure I understand what you're asking for and ask any clarifying questions.

### Step 2: Planning  
I'll break it down into small steps (max 5 at a time) and show you:
- What files will change
- What each step does
- Any concerns or tradeoffs

### Step 3: Your Approval
I'll wait for you to say "go ahead" before making changes.

### Step 4: Implementation
I'll make the changes, stopping every few steps to check in.

### Step 5: Review
Before saving, I'll verify everything is correct.

## What You'll See

```
## 🎯 Feature: [what you asked for]

### My Understanding
[Plain English description of what I'll build]

### What Gets Changed
- [file]: [what changes]
- [file]: [what changes]

### Steps (I'll do these one at a time)
1. [First thing I'll do]
2. [Second thing]
3. [Third thing]
...

### Questions (if any)
[Anything I need clarified]

Ready to proceed? Say "go ahead" to start.
```

## Along The Way

After every few changes, I'll stop and show you:
- What I just did
- What's next
- Ask if you want to continue

## When It's Done

I'll run /project:review to make sure:
- Code is going to the right place (your Gitea)
- No AI attribution
- Works on all platforms

# /project:fix - Fix a Bug or Problem

Use this when something isn't working right.

## How It Works

### Step 1: Describe the Problem
Tell me:
- What's happening (or not happening)
- Any error messages you see
- When it started or what you were doing

### Step 2: Investigation
I'll look at the relevant code and figure out what's wrong.

### Step 3: Diagnosis  
I'll explain:
- What I found
- Why it's happening
- How to fix it

### Step 4: Your Approval
I'll wait for you to approve the fix before changing anything.

### Step 5: Fix It
I'll make the repair, testing as I go.

### Step 6: Verify
Make sure the fix works and didn't break anything else.

## What You'll See

```
## 🔍 Bug Investigation: [the problem]

### What I Found
[Explanation in plain English]

### The Cause
[Why this is happening]

### The Fix
[What I'll change to fix it]

### Files Affected
- [file]: [what changes]

### Risk Level
[Low/Medium/High] - [explanation]

Ready to apply the fix? Say "go ahead" to proceed.
```

## After the Fix

I'll run /project:review to make sure:
- The fix is going to the right place (your Gitea)
- The fix works on all platforms
- Nothing else got accidentally broken
